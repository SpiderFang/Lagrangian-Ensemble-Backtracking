### 2.3 `Behavior` 新增三個欄位

```python
settling_velocity_slow_bound_mps: float   # 該類導出區間中絕對值最小者（最慢），負值
settling_velocity_fast_bound_mps: float   # 該類導出區間中絕對值最大者（最快），負值
derivation_source: str                    # 固定 "data/settling_velocity_derivation/results.csv"
```

**刻意不用 `min`/`max` 命名**：這些是負值，絕對值最大者在數值上最小，用 min/max 會讓任何 `min <= max` 的檢查誤判。

## 7. 成果表述的硬性限制

新十檔全部落在 ≥0.01 m/s，依專案自身診斷，此區間的粒子逆時間不到 1 小時即抵達近表層，整段軌跡實質為表層漂流。**預期十檔的來源足跡彼此高度相似。**

因此下游報告與圖表必須遵守：

1. 主詞用 `settling_velocity_mps` 數值或分群，`oca_category_zh` 只能作附註。**不得**寫成「鋁罐與鐵罐來自不同方向」。
2. 明確寫出：類別**內**的速度跨幅（1.6×–120×）大於類別**間**的跨幅（整體 33×）。
3. 十檔相似是**物理結果不是設計失敗**——舊設計看似可區辨，正因為數值慢到屬於微塑膠尺度。這句話要主動寫進限制或討論章節，不要等審查時才解釋。
4. 真正承載資訊的是另外兩個軸：5 個水平位置 × 50 個到達時刻。季節、大小潮與極端事件造成的來源差異才是本成果的主要內容。
